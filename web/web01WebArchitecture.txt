What kind of Web applications
can we develop?














Web site

a system on which a Web server is running, hosting a set of related pages (resources)


of an organization, company, or person(s)














Web application

a collection of interconnected Web pages having the content dynamically generated,
in order to offer a specific functionality to its users














Web application

the interaction between application and users is facilitated by a Web interface
