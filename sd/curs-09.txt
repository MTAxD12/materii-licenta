Function succesor(t)
begin

/*min(t → drp)*/

Arbori AVL

I Teoremă
Clasa arborilor AVL-echilibraţi este O(log n) stabilă.

I Algoritmul de inserare/ştergere
I Nodurile au memorate şi factorii de echilibrare (−1, 0, 1).
I Se memorează drumul de la rădăcină la nodul adăugat/şters ı̂ntr-o
stivă (O(log n)).
I Se parcurge drumul memorat ı̂n stivă ı̂n sens invers şi se reechilibează
nodurile dezechilibrate cu una dintre operaţiile: rotaţie stânga/dreapta
simplă/dublă (O(log n)).

Inserare: algoritm
Procedure echilibrare(t, x)
begin
while (x! = NULL) do
/* actualizeaza inaltimea h(x) */
if (h(x → stg ) ≥ 2 + h(x → drp)) then
if (h(x → stg → stg ) ≥ h(x → stg → drp)) then
rotatieDreapta(t, x)
else
rotatieStanga(t, x → stg ); rotatieDreapta(t, x)
else
if (h(x → drp) ≥ 2 + h(x → stg )) then
if (h(x → drp → drp) ≥ h(x → drp → stg )) then
rotatieStanga(t, x)
else
rotatieDreapta(t, x → drp); rotatieStanga(t, x)
x ← x → pred
end

I Avantaje:
I Complexitatea operat, iilor de căutare, inserare şi ştergere este O(log n).

I Dezavantaje:
I Spaţiu suplimentar pentru memorarea ı̂nălţimii / factorului de

I Sunt preferaţi când avem de realizat mai multe căutări şi mai puţine
