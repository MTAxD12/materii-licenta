Sortare prin interschimbare (bubble-sort)
I Principiul de bază:
I (i, j) cu i < j este o inversiune dacă a[i] > a[j]
I Cât timp există o inversiune (i, i + 1) interschimbă a[i] cu a[i + 1]

I Algoritm:
Procedure bubbleSort(a, n)
begin
ultim ← n − 1
while (ultim > 0) do
n1 ← ultim–1; ultim ← 0
for i ← 0 to n1 do
if (a[i] > a[i + 1]) then
swap(a[i], a[i + 1])
ultim ← i
end

Sortare prin selecţie naivă
I În ordinea n − 1, n − 2, ..., 1, 0, adică:
(∀i)0 ≤ i < n =⇒ a[i] = max{a[0], ..., a[i]}
Procedure naivSort(a, n)
begin
for i ← n − 1 downto 1 do
imax ← i
for j ← i − 1 downto 0 do

imax ← j

Interclasarea a două secvenţe sortate

I problema:
I date a[0] ≤ a[1] ≤ · · · ≤ a[m − 1], b[0] ≤ b[1] ≤ · · · ≤ b[n − 1], să se
construiască c[0] ≤ c[1] ≤ · · · ≤ c[m + n − 1] a.ı̂.
(∀k)((∃i)c[k] = a[i]) ∨ (∃j)c[k] = b[j]) iar pentru k! = p, c[k] şi c[p]
provin din elemente diferite

I soluţia
I iniţial: i ← 0, j ← 0, k ← 0
I pasul curent:
I daca a[i] ≤ b[j] atunci c[k] ← a[i], i ← i + 1
I daca a[i] > b[j] atunci c[k] ← b[j], j ← j + 1
I k ←k +1

I condiţia de terminare: i > m − 1 sau j > n − 1
I daca e cazul, copie ı̂n c elementele din tabloul neterminat

Quick sort: partiţionare
I iniţial:
I x ← a[p] (se poate alege x arbitrar din a[p..q])
I i ← p + 1; j ← q

I pasul curent:
I dacă a[i] ≤ x atunci i ← i + 1

I operaţii

Procedure partitioneaza(a, p, q, k)
begin

i ←p+1
j ←q
